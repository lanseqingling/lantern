# 编辑器体验

## 1. 文档定位

本文定义 Lantern AI 工作台的空间结构、视觉语言、对象反馈、直接编辑、参考使用、候选确认和阅读预览规则。产品范围见[产品需求](./prd.md)，作品对象归属见[LCD](./lcd.md)。

工作台遵循本文的交互与视觉规则。本文不描述组件内部状态、API 或模型任务实现。

## 2. 交互原则

### 一个持续创作空间

角色、场景、分镜、编排、单格精修和阅读检查不拆成强制向导。用户在一话工作台中围绕同一份工作稿移动焦点，必要时进入漫画首页、资产空间或阅读预览。

### 漫画内容第一

漫画纸张和画格始终是视觉主体。参考图、抽屉、工具条、对话和候选以辅助层进入同一空间，不遮蔽当前编辑对象，不把任务过程做成画布作品对象。

### 直接操作与 AI 协作分工

- 选择、移动、缩放、裁切、文字和气泡调整等确定性操作直接完成，并进入可撤销工作稿。
- 需要生成、自然语言理解、结构调整或多对象处理的动作进入右侧对话，并先产生候选或页面方案。
- 人类操作与 AI 协作使用同一对象语义、影响范围、校验和回退方式。

### 按风险显示信息

普通直接编辑只显示当前对象与必要工具。AI 准备行动或产出候选时，用户需要看懂焦点、意图、关键参考和影响范围。跨格、整页、整话、格式切换和覆盖已确认内容的动作必须额外确认。

## 3. 工作台结构

工作台以全屏点阵画布为底层，主要区域均为悬浮界面：

| 区域 | 主要内容 | 交互职责 |
|---|---|---|
| 左上项目入口 | Lantern 标识、漫画/一话和工作稿摘要 | 返回首页或漫画、进入资产空间、保存、预览和打开开发上下文。 |
| 左侧创作空间 | 资产、分镜、页面方案和漫画页或滚动段 | 定位素材与作品结构，不承载任务目录。 |
| 中央漫画舞台 | 当前页面、画格、格内元素、参考图与候选预览 | 直接选择、编辑、比较和检查作品。 |
| 右侧对话 | 会话、消息、追问、任务事件、候选和输入区 | 处理需要理解、生成或确认的协作。 |
| 底部创作工具 | 选择、平移、页面或设备视区查看、上传、编排、文字、Undo/Redo、AI 与预览 | 提供高频直接动作和模式入口。 |

左右抽屉可以收起。抽屉覆盖画布视口，不改变 LCD 坐标，也不改变参考图在画布世界中的位置。

### 左侧创作空间

左侧上半区在“资产”和“分镜”之间切换：

- 资产：显示当前创作空间可用素材，可定位到画布、添加到画布、引用到对话、改名或移除列表项。
- 分镜：显示页面方案和按画格组织的单格画面。选择分镜条目会定位对应画格；没有主分镜的画格可以就地创建并绑定。

下半区固定显示作品缩略图、名称、编号、当前位置、画格数和新增入口。页漫称为“漫画页”，点击新增即创建空白页；条漫称为“滚动段”，新增时从 `4:3`、`1:1`、`3:4`、`2:3`、`9:16`、`9:20` 中选择宽高比。比例只决定新段高度，段宽沿用当前条漫，阅读时各段无缝连接。列表项悬浮时显示更多菜单，可以编辑名称或删除；名称留空时按阅读顺序显示默认页名。滚动段还可以使用同一组比例调整底部高度，但不能裁掉已有画格。删除需要确认并至少保留一个页面。列表是作品导航，不显示任务状态。

### 中央漫画舞台

- 聚焦选择模式用于选择和编辑漫画对象；自由画布模式只移动视口。
- 单页/双页查看只改变工作台查看方式。真正双页由作品结构明确创建。
- 条漫聚焦模式保持各滚动段连续渲染，切换段时平滑滚动到目标位置。滚动期间短暂显示不可操作的位置视图，停止后自动淡出。
- 条漫可循环切换关闭、手机 `9:16`、长屏手机 `9:20` 和平板 `3:4` 设备视区。取景框固定在工作台可视区中央，内容从框内滚过；空间不足时取景框与条漫画布同步等比缩小。该状态只辅助编排，不写入作品、快照或导出。
- 参考图可以在画布中移动、缩放和调整层级，但不会进入漫画成稿。
- 候选预览覆盖当前工作稿的对应结果，提供原稿/新方案切换，不立即创建 revision。
- 选择框、辅助线、对象工具条和编辑浮层属于交互层，预览与导出时隐藏。

### 右侧对话

右侧保留可回看的长对话。每个会话属于当前 Project；切换会话只切换消息、未应用候选和当前任务上下文，不切换作品工作稿。

会话抽屉支持新建、切换、重命名和删除。删除会话不删除已经应用的作品内容。

输入区包含：

- 文字输入。
- 本轮图片附件。
- 当前创作意图快捷选择。
- 当前对象或显式对象引用。
- 发送或停止当前任务。

同一会话同一时间只运行一个任务。任务运行时旧作品保持可见，用户可以停止任务；完成后仍需通过候选确认进入作品。

## 4. 作品层、参考层和协作层

### 漫画作品层

漫画层对应 LCD 的 `PresentationUnit → PageSurface → Frame → Layer → Element`：

- PresentationUnit：一次共同阅读和编排的页面、双页或条漫段。
- Frame：画格容器，可移动、缩放、调整样式并绑定单格画面。
- ArtElement：格内成稿或多层画面；取景只修改 crop。
- Dialogue / BalloonElement：对白语义与气泡视觉实例。
- Unit Overlay：破框、跨格和跨页对象。

直接编辑必须作用于正确对象层级。移动画格不能改写格内坐标，调整取景不能移动 Frame，参考图也不能通过拖拽直接变成成稿。

### 画布参考层

画布参考图用于对照和显式引用，不进入 LCD、阅读预览或导出。

- 上传到画布的图片创建可持久化的素材与摆放关系。
- 参考图可以移动、缩放、调整层级、改名、保存到漫画资产或从画布移除。
- 保存为资产后，画布摆放与来源 Asset 仍是两个关系；移除摆放不删除 Asset。
- 修改图片内容创建新 AssetVersion，移动、缩放或改显示名不创建图片版本。
- 将参考真正放入成稿时，在目标 Frame 图层或 Unit Overlay 创建元素并固定引用 AssetVersion。

对话输入区上传只作为本轮消息附件，不自动创建画布参考图或漫画资产。

### 候选与任务

任务事件只显示在对话中。候选可以显示在消息、画布候选卡或页面方案区，但在用户应用前不属于工作稿。

Candidate 必须显示：

- 结果标题和简短变更摘要。
- 作用范围或目标对象。
- 可用、已应用、已撤回、已丢弃或已过期状态。
- 预览、应用、继续完善、丢弃或重新生成等适用动作。

页面 Candidate 可以保存为 PageVariant。页面方案支持原稿/新方案比较、应用、重新应用和删除；布局方案重新应用时保留格内内容。

## 5. 选择、焦点和编辑状态

### 选择规则

- 点击画格选择 Frame；点击格内图片选择 ArtElement；点击气泡选择 BalloonElement；点击参考图选择摆放对象。
- 选中对象后，只显示该对象可执行的直接动作。
- 左键选择显示对象编辑工具栏，承载移动、缩放、裁切、对白和单格画面等直接编辑；右键命中最具体的页面对象并显示对象管理菜单，承载新增、复制、更换和删除。对象编辑工具栏的“更多”打开同一份管理菜单。
- 右键纸张空白处显示纸张管理菜单并可在指针附近新增画格；右键图片和气泡不得退回选择其父画格。
- 双击或明确编辑动作进入裁切、对白或单格画面编辑，不依赖隐式模式。
- 点击空白区退出对象编辑；打开一个浮动菜单时关闭同级其他菜单。
- 多选模式明确区分漫画对象与画布参考对象，只有允许的组才能批量移动或移除。

### 直接编辑

| 用户动作 | 作品变化 |
|---|---|
| 拖动画格 | 只修改 Frame 位置。 |
| 缩放画格 | 修改 Frame geometry，不改格内局部坐标。 |
| 拖动格内图片 | 修改 crop 或局部 transform。 |
| 在纸张空白处新增画格 | 创建带标准画面层和对白层的矩形 Frame，并按页面位置进入阅读顺序。 |
| 放入、更换或移除格内图片 | 创建、替换或移除当前 Frame 的主 ArtElement；来源资产及其他引用不变。 |
| 新增或删除对白 | 以一个复合能力创建或移除 Dialogue 与 BalloonElement。 |
| 编辑单格画面 | 创建或更新当前 Frame 的 primary StoryboardBeat。 |
| 编辑对白 | 修改 Dialogue 内容，保留气泡位置。 |
| 调整气泡 | 修改气泡形状、位置、尺寸或尾巴，不重生成画面。 |
| 移动参考图 | 只修改画布摆放。 |

### 对象归属与跨层编辑

- 选中作品对象时显示 `格内`、`破格`、`纸面`或`跨页`状态；状态来自 LCD，不由视觉位置猜测。
- 新画格默认不能重叠，新格内元素默认不能拖出画格；普通拖动只修改当前层的位置。
- 对象到达画格边界时显示阻力和可投放目标，不自动改变归属。新增或拖放时高亮画格与纸面，落入画格创建格内对象，落在纸面空白创建 Unit 对象。
- 右键和对象工具栏“更多”共用跨层动作：移出画格、收回画格、转为纸面对象、关联到画格、调整前后层级、设为叠格或取消叠格。只显示当前对象适用的动作。
- 跨层转换保持对象视觉位置不跳变，并作为一次可撤销 ChangeSet 提交。视觉层级变化不自动改变画格或文字阅读顺序。

一次连续拖拽在提交时只形成一个 Undo 单位。Undo / Redo 作用于作品 revision；未应用候选和对话消息不进入作品撤销历史。

## 6. 意图、作用范围和引用

输入区的意图选择是快捷提示，不是强制模式。系统结合自然语言、当前选择和显式引用判断本次协作。

常用作用范围：

| 范围 | 含义 |
|---|---|
| 仅参考 | 只创建或维护参考，不修改作品。 |
| 当前元素 | 只影响选中的图片、文字或气泡。 |
| 当前画格 | 只影响当前 Frame 和其单格画面。 |
| 当前页面 | 只影响当前 PresentationUnit。 |
| 从这里往下 | 只追加当前锚点之后的内容。 |
| 整话 | 影响多个页面或全章结构，需要独立确认。 |

显式引用可以来自漫画格、气泡、画布参考图和漫画资产。发送时保存对象 ID 与固定 versionId；后续资产更新不能改变旧消息的引用。系统可以自动补充高相关上下文，但关键自动参考应可解释，不在输入框常驻堆叠。

## 7. 典型流程

### 调整当前格

```text
选择画格或格内图片
  → 直接调整 Frame / crop / 单格描述
  或输入自然语言要求
  → 查看只影响当前格的图片候选
  → 预览、应用或丢弃
```

### 创建并使用参考资产

```text
上传图片到画布或从资产空间导入
  → 在画布对照、改名和摆放
  → 保存为漫画资产
  → 引用到当前对话或目标画格
```

### 页面重编排

```text
选择当前页面或多个画格
  → 说明节奏目标
  → 生成页面方案
  → 在画布切换原稿 / 新方案
  → 保存方案、应用或取消
```

应用布局方案时按稳定 Frame ID 保留格内内容。方案过期时不能静默覆盖当前工作稿。

### 预览、保存与返回

```text
保存工作稿为快照
  → 进入阅读预览
  → 隐藏参考与编辑控件
  → 按作品阅读顺序查看
  → 返回对应页面继续编辑
```

预览只读取最近保存快照中的 LCD 与固定资源版本，不读取当前工作稿、对话、参考摆放或临时选择。下载菜单可以保存当前阅读范围的 PNG，也可以下载该已保存版本中不含临时资源地址的 LCD JSON。

## 8. 响应、动效与可访问性

- 桌面端优先保证中央漫画可读、左右抽屉可收起和浮层不遮挡当前对象。
- 关键状态不能只依靠颜色；选中、候选、失败、过期和禁用需要文字、图标或形状辅助。
- 所有图标按钮提供可读名称，菜单与对话支持键盘焦点和 Escape 关闭。
- 拖拽之外提供按钮或表单完成关键操作。
- 动效只解释焦点、抽屉、候选比较和模式变化，不能延迟保存、应用或路由反馈。
- `prefers-reduced-motion` 下取消非必要位移和缩放。

## 9. 视觉语言

### 漫画内容第一

纸张、画格、成稿和对白是最高视觉层级。侧栏、对话、候选和工具围绕内容出现，不把工作台做成后台控制台、流程图编辑器或传统专业绘图软件。

### 轻、圆润、有空间感

界面使用冷白稿纸、低对比点阵、半透明浮层、柔和阴影和较大圆角。层级主要依靠空间、明度和轻阴影，不依赖粗边框或大面积高饱和色块。

### 颜色语义

- 青色：选择、焦点、引用、结构辅助、当前工具和可编辑边界。
- 琥珀：等待确认、生成推进、关键候选和需要用户注意的下一步。
- 红色：失败、阻塞性错误和不可逆风险的二次确认面。一级菜单中的删除或移除是进入确认流程的普通入口，使用中性文字与图标。

普通选中不使用琥珀，避免把所有操作都表现为待确认。状态不能只依赖颜色，必须同时提供文字、图标、边框或形状表达。

## 10. Visual Tokens

以下视觉 token 定义工作台的稳定颜色语义，具体界面应保持一致使用。

### Color

| Token | 定义值 | 用途 |
|---|---:|---|
| Canvas | `#f6f8f9` | 应用和画布背景。 |
| Paper | `#ffffff` | 漫画纸张、卡片和高层浮层。 |
| Ink | `#172026` | 主文字和高对比图标。 |
| Muted | `#68747c` | 次级文字、说明和停用信息。 |
| Cyan | `#64c8c8` | 选中、结构和主要交互提示。 |
| Cyan Deep | `#247f82` | 青色文字、图标与强调边界。 |
| Cyan Soft | `#e8f8f8` | 青色浅背景和 hover。 |
| Amber | `#f2b84b` | 候选、推进和注意状态。 |
| Amber Soft | `#fff3cf` | 等待确认的浅背景。 |
| Danger | `#d85b5b` | 失败、阻塞性错误和危险动作的二次确认背景；不用于一级操作入口。 |

边框使用 Ink 或 Cyan 的低透明度变体。Glass surface 使用接近白色的透明背景和 backdrop blur；正文保持足够对比度。

### Typography

默认字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
```

- 页面与对话标题紧凑、较高字重，避免超大营销字号进入工作台。
- 正文以可读性为先，保持舒适行高。
- 标签与状态可以使用小字号和高字重，但必须有可读文案。
- 代码与调试内容使用等宽字体，不与普通用户界面混用。

### Radius、Shadow 与 Spacing

- 纸张使用小圆角；输入、按钮和工具使用中圆角或胶囊形；卡片、抽屉和对话使用大圆角。
- 阴影只用于悬浮层级，不给每个列表项增加独立重阴影。
- 通用间距以 4 / 8 / 12 / 16 / 24 / 32 为基础，密集工具组可以使用更小内部间距。

### Motion

- hover、focus、菜单和图标状态使用约 140ms 的快速反馈。
- 抽屉、候选和焦点切换使用约 180–240ms 的过渡。
- 路由、保存、应用和停止任务先立即反馈，再执行非必要动效。
- 动效不改变 LCD 坐标，也不制造作品已经修改的错觉。

## 11. 通用界面原语

### Floating Surface

用于项目菜单、抽屉、对话、对象检查器和候选工具条。统一使用浅色或半透明背景、细边框、大圆角和柔和阴影；相同层级共享 padding、菜单分区和关闭方式。

### Button

- Primary：应用、保存、创建等明确推进动作。
- Secondary：预览、继续修改和普通工具。
- Ghost / Icon：高频画布工具和菜单入口。
- Danger：只用于删除、丢弃或明确风险动作的二次确认。一级操作入口保持中性，触发后再由确认层说明影响范围并承接风险表达。

图标按钮必须有可读名称。禁用按钮降低强调，同时保留禁用原因。

### Menu

- 按导航、对象操作和危险操作分区。
- 使用固定 UI 尺度，不随对象或画布缩放。
- 同级只允许一个菜单打开；点击外部或 Escape 关闭。
- 危险动作与普通动作之间有清楚分隔。

### Drawer

- 左侧创作空间和右侧对话都可以收起与恢复。
- 抽屉内部滚动不移动画布。
- 抽屉开合不改变作品或参考对象坐标。
- 收起后在可见视区保留恢复入口。

### Delete Confirmation

- 删除资产图片、纸面元素、漫画页、滚动段、一话或漫画使用同一个居中二次确认组件。
- 一级入口保持中性；确认层统一显示删除图标、影响范围、取消和确认动作。
- 禁止删除时仍显示原因，并停用确认动作。

### Custom Select

- 触发器显示当前值和展开状态。
- 选项支持标题、简短说明和禁用状态。
- 菜单避免超出视口，支持键盘导航与 Escape。
- 不将互斥选项做成长期占据画面的模式 chip。

### Object Toolbar / Inspector

- 靠近当前选择，并避开相邻画格与左右抽屉。
- 只显示当前对象适用的动作。
- 直接编辑优先使用短工具条；需要文字或属性输入时打开轻量检查器。
- 管理动作使用带文字的上下文菜单；右键和对象工具栏“更多”共用同一入口，不复制动作定义。
- 对象管理菜单标题只显示对象图标、类型和两位编号，例如 `画格 01`、`旁白框 01`、`Page 01` 或 `滚动段 01`，不重复显示“对象管理”副标题。
- 拖拽期间不反复重排工具条，提交后再更新位置。

### Candidate Card / Compare Toolbar

- 显示标题、范围、简短变更摘要和状态。
- 按结果类型提供预览、应用、继续完善、保存方案或丢弃。
- 页面方案比较使用“原稿 / 新方案”切换，不能让用户误以为预览已经写入作品。
- 过期候选说明原因，并提供基于当前工作稿重新生成的入口。

### Composer

- 文本输入是视觉主体，显式引用与图片附件以可移除标签显示。
- 意图选择、引用当前对象、附件和发送动作位于输入区底部。
- 任务运行时发送动作切换为停止；不能同时提交第二个任务。

## 12. 漫画与参考视觉

### Comic Paper

- 白色纸张、轻边框和克制阴影。
- 当前页面使用小型页面标签，不增加大标题条。
- 画格边框、遮罩、阅读顺序和纸面辅助线只服务漫画编辑语义。
- 单页与双页查看保持同一种纸张语言；真正双页显示装订关系。

### Selection Focus

- 画格、格内图片、气泡和参考图使用各自合适的选中轮廓。
- 选中框不进入预览和导出。
- 裁切态明确区分“移动图片取景”和“移动整个画格”。
- 多选同时表达漫画对象组和参考对象组，避免跨层误操作。

### Reference Image

- 图片主体优先，名称和操作只在 hover、focus、选中或菜单中出现。
- 图片可以自由缩放，但菜单、标签和操作按钮保持固定屏幕尺寸。
- 参考图与漫画纸张保持清楚层级，不能看起来像已经进入成稿。

## 13. 状态、图标与 QA

| 状态 | 视觉要求 |
|---|---|
| Default | 低强调，内容优先。 |
| Hover | 轻背景或边界变化，不产生位移。 |
| Focus / Selected | 青色结构提示与清楚轮廓。 |
| Referenced | 显示引用标识和可移除关系。 |
| Candidate | 琥珀或中性候选标签，保留范围说明。 |
| Running | 轻量进度和停止入口，旧内容保持可见。 |
| Applied / Saved | 明确文字状态，不持续高亮。 |
| Failed | 错误提示、原因和重试入口。 |
| Stale | 降低强调，说明基于旧工作稿且不可直接应用。 |
| Disabled | 降低对比，同时保留可辨标签或原因。 |

图标使用统一线性语言、圆角端点和接近的 stroke weight。常用概念保持稳定：选择、平移、页面、资产、编排、文字、AI、预览、撤销、重做、保存和删除。陌生动作在菜单中使用图标加文字。

视觉与交互 QA 至少检查：

- 漫画纸张是否仍是第一视觉主体。
- 左右抽屉收起后是否保留恢复入口。
- 浮层是否避开当前选择且不超出安全视区。
- 直接编辑、候选预览和已应用状态是否容易区分。
- 菜单、选择器和对话是否可以键盘操作并正确关闭。
- 预览与导出是否隐藏全部编辑辅助层。
- 画布缩放后，UI 菜单和标签是否仍保持固定可读尺寸。
