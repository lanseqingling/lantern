# 使用 MCP + Skill 与外部 Agent 创作

Lantern 的 MCP 提供漫画、章节、资产、页面、画格、图片和文字等受控能力，配套 Skill 帮助外部 Agent 理解作品结构与基础漫画编排。Agent 负责理解、规划和视觉分析；新图片由 Agent 自身的生图能力提供，也可以直接使用用户上传的 PNG、JPEG 或 WebP。

## 开始前

先启动 Lantern，再安装或同步外部 Agent 接入：

```bash
./lantern start
./lantern agent:install
```

Windows 使用 `lantern.cmd`。安装后重启外部 Agent。对话中可以使用漫画与章节的准确名称，也可以直接粘贴 Lantern 本地页面链接；不需要查找或提供内部 ID。

外部 Agent 对一话的页面、画格、图片和文字修改会连续写入隔离草稿，不会边做边改动正式工作稿。任务完成后，Agent 返回一个本地审查链接；也可以从工作台右上角的历史入口找到同一方案，在对比画布中选择应用并保存、保留或丢弃。

## 完成第一页

按照下面的顺序创建作品、完成一页，再继续调整。支持显式调用 Skill 的 Agent 可以在指令开头使用 `$create-with-lantern`。

### 创建作品与资产

```text
使用 $create-with-lantern 创建页漫《海风经过教室》，阅读方向从右到左，并创建第一话“放学后的屋顶”。
建立女主角“青木澪”（黑色齐肩短发、夏季水手服）和场景“临海高中旧校舍”（长走廊、推拉窗、临海）两个资产。
全篇采用清新的日式黑白页漫画风：纯黑白线稿、灰阶网点和明亮留白。使用你自己的生图能力为两个资产各生成一张基准图，上传到对应资产并设为主要图片。
```

### 编排正文页

```text
在《海风经过教室》第一话中创作一张无对白正文页：
第一格用横向大格表现放学后的校园远景；下半页从右向左依次是风吹起教室窗边白色窗帘的第二格，以及青木澪独自收拾书包并望向门外的第三格。
请使用日式黑白漫画画面完成画格、图片、裁切和页面编排，并查看最终页面后调整明显的问题。
```

Skill 会指导 Agent 按画格准备独立图片，再由 MCP 完成可编辑编排；除非用户明确要求，不应把多个画格预先画进一张扁平图片。

完成后打开 Agent 返回的方案链接。确认画格、图片和裁切符合预期，再选择“应用并保存”；如果只想留下这个方向，选择“保留方案”。

### 调整页面

```text
让刚才页面下半部的第二格更醒目：保留顶部第一格，适度加宽第二格，并同步收窄第三格。
保留现有图片和原有格间距，重新裁切受影响的两张图片；让阅读顺序仍然清楚，修改后再检查整页效果。
```

## 修改已有页面

直接粘贴从 Lantern 复制的本地链接，告诉 Agent 要保留和改变什么：

```text
使用 $create-with-lantern 重新编排这个页面：<从 Lantern 复制的本地链接>
保留全部图片，让最后一格更突出，并减少前两格之间不必要的留白。
```

## 继续创作

### 扩展为连续页面

```text
为当前章节继续创作三页无对白漫画：青木澪在走廊发现一张遗落的乐谱，循着钢琴声走上楼梯，在最后一页翻页后看见夕阳中的屋顶和等待她的少年。
先做必要的跨页节奏规划，再逐页完成可编辑画格和图片编排。夕阳和光影也使用黑白线条与灰阶网点表现，保持人物、校园场景和日式黑白画风一致。
```

### 使用跨页与破格

```text
把当前相邻两张正文页合并为真正双页，用夕阳下的校园屋顶全景连接左右页面。
关键人物和视觉焦点避开中缝；让青木澪被海风吹起的发梢从所属画格受控破格，但不要影响阅读顺序。
```

### 添加对白和旁白

```text
在当前页给两位角色添加三句对白，并在纸面顶部添加一句旁白。
根据阅读方向安排气泡顺序，避开脸部和关键动作，保留清楚的尾巴指向。
```

### 检查一致性和分镜

```text
检查当前页和下一页的人物、场景与视觉风格一致性，并分析动作衔接、阅读节奏和翻页揭示。
请区分可见问题、结构事实和创作建议，不要自动修改。
```

### 对比工作稿和已保存版本

```text
比较当前工作稿与最近保存版本的这一页，说明画格、裁切、图片、文字和最终视觉效果发生了什么变化，不要修改作品。
```

## 描述创作需求

- 说明目标结果、故事意图和必须保留的内容，不需要指定 MCP 工具名或内部对象 ID。
- 修改现有内容时，优先粘贴 Lantern 链接，或提供准确的漫画、章节和页面名称。
- 需要新图片时，可以让外部 Agent 使用自身生图能力，也可以要求它使用你提供的图片。
- 需要保持一致的人物、场景或道具，应明确要求复用 Lantern 中已有的固定资产版本。
- 页面、章节或漫画等破坏性删除需要确认准确目标；不要用“把没用的都删掉”代替确认。
- Agent 只能使用 Lantern 当前开放的能力。暂不支持的专业自由编排或图片精修不会因为 Prompt 描述而自动出现。
