# 文档

## 阅读顺序

1. [产品概要](./product.md)：产品为什么存在、服务谁、坚持什么。
2. [产品需求](./prd.md)：用户能力、对象生命周期、产品范围与验收。
3. [编辑器体验](./editor.md)：工作台交互、视觉系统、状态、动效和可访问性。
4. [LCD](./lcd.md)：作品结构、坐标、分层、资源引用和写入不变量。
5. [Agent](./agent.md)：协作模式、上下文、任务、候选和安全边界。

运行中的工作台是交互与视觉实现基线。未进入正式事实源的工作由[迭代路线](./roadmap.md)跟踪；完成后删除待办细节和小标题，只保留主章节标题与一句结果。

## 事实源

| 事实 | 来源 |
|---|---|
| 产品身份、目标用户和原则 | 产品概要 |
| 用户能力、范围和验收 | 产品需求 |
| 工作台交互、视觉和对象反馈 | 编辑器体验 |
| LCD 语义与不变量 | LCD |
| Agent 协作、上下文与执行边界 | Agent |

文档发生冲突时，先按职责确定唯一事实源，再直接修正其他文档，不新增补充说明。

## 生命周期基线

| 内容 | 含义 | 写入方式 |
|---|---|---|
| 工作稿 | 用户正在编辑的一话 | 确定性编辑或候选应用通过 ChangeSet 创建新 revision |
| 候选 | 尚未采用的生成、结构或高风险结果 | 预览后显式应用，不能静默覆盖工作稿 |
| 页面方案 | 可复用的编排或局部页面方案 | 可预览、重新应用和删除，不等于当前作品 |
| 保存快照 | 阅读和导出的不可变基线 | 用户显式保存，后续编辑不能原地改写 |

会话、消息、任务、画布参考卡和未应用候选不是作品事实。预览与导出只读取 LCD 和固定资源版本。

## 维护规则

- 一个概念只在一份正式文档中完整解释，其他文档使用短引用。
- 正式文档直接描述规则与验收，不记录旧方案、阶段过程或完成日志。
- 临时迭代路线可以保留已完成主章节的标题与一句结果，不保留小标题，也不记录日期、过程或变更清单。
- 除 Agent 文档和临时迭代路线外，`docs/` 不引用源码路径和内部实现符号，也不承担代码导航；LCD 中的稳定对象名与字段名属于作品协议词汇。仓库导航由根目录文档维护，迭代路线只保留完成未决工作所需的实现入口。
