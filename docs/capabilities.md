# 漫画能力矩阵

`✅` 已接入　`🟡` 部分接入　`❌` 未接入　`⚪` 不涉及

`✅` 表示该入口可以形成可用结果并进入相应生命周期；`🟡` 表示已有基础链路，但范围或结果闭环仍有限；`❌` 表示不能通过该入口完成；`⚪` 表示按该入口职责不承担。
