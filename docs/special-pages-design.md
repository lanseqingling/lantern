# 线上章节特殊页设计稿（已确认）

> 本文记录已确认的开发设计；实现完成后，最终规则应分别收敛到产品需求、编辑器体验与 LCD。

## 目标与范围

让创作者在一话线上漫画中加入少量、可阅读的非正文页面，同时继续复用现有的页面、双页、画格、文字、图片、预览和导出能力。

首版只解决页漫一话的线上阅读，不引入纸质出版、版权页、目录、广告、番外或独立人物设定页。

## 概念

`PresentationUnit` 继续描述画布和物理结构；新增的页面角色描述读者会如何理解这一个展示单元。页面角色不改变对象、资源、坐标或渲染模型。

| 页面角色 | 含义 | 位置与数量 | 默认阅读方式 |
| --- | --- | --- | --- |
| `story` | 正文漫画页 | 任意位置、可重复；默认值 | 沿用普通单页/双页阅读规则 |
| `cover` | 本话的可选入口主视觉 | 最多一个，始终位于本话最前 | 独立展示 |
| `interlude` | 正文前或正文中的标题、时间地点切换、情绪停顿或简短说明 | 任意位置、可重复 | 独立展示 |

`cover` 和 `interlude` 均是“特殊页”，不是新的画布类型。它们可以包含全幅图片、文字、气泡或普通画格；空白画布也是有效起点。

创作者的人设继续属于漫画级角色资产与设定卡，用于创作一致性和 Agent 上下文，不进入读者页。需要展示给读者的人物简介，以 `interlude` 的图文内容表达，不创建 `character` 页面角色。

章节列表的封面图片仍是章节元数据；阅读流中的 `cover` 是作品 LCD 内的一页。两者不自动同步，避免章节卡更新改写已保存阅读内容。

## 单页、双页与顺序

- 首版不支持封面（首页）合并为双页；真正双页可由两个相邻且同为 `story` 或同为 `interlude` 的单页合并而成，不同角色不能合并。
- 普通双页查看在跳过 `cover` 后，自动配对两个相邻的 `story` 或 `interlude` 单页；真正双页永远独立显示。`cover` 独立显示，不参与正文页码或双页配对计算。
- 所有角色均存在于同一 `unitOrder`，会参与上一页、下一页、阅读进度、快照和导出顺序；封面不占用正文物理页码，正文第一页从 `01` 开始。
- 真正双页始终是一个展示单元，保留当前共享坐标、跨页对象和按左右纸面导出的语义；页面角色不会改变这些规则。

此前允许封面成为真正双页，是为了容纳横向主视觉或跨中缝构图；它在视觉上相当于读者打开本话后看到的一张全景开场图，而不是纸质书的封面纸。首版不提供这一能力：现有真正双页由两个单页合并而来，这会与“封面最多一个且固定首位”产生额外的创建、合并、拆分和角色归属规则。单页封面已满足线上一话的入口需求；未来若确有需要，应新增“直接创建封面双页”的独立入口，而不是把封面与正文页合并。

## 工作台交互

### 创建与变更

页面列表的新增入口展开为三个明确选项：**正文页**、**封面页**、**过场页**。

- 新增正文页沿用当前行为：插入当前页之后或追加到末尾。
- 新增封面页直接插到最前；已有封面时入口不可用，并提示定位到已有封面。
- 新增过场页插到当前页之后；没有当前页时追加。创建后打开空白画布，用户按现有方式放入图片、文字或画格。
- 创建后页面角色固定。首版不提供“设为封面 / 设为过场 / 设为正文”的入口；需要另一种类型时，新建对应页面并按现有对象编辑能力重新制作内容。

首版不提供“封面模板”“人物卡模板”等生成式或固定版式模板。用户先得到与普通页一致的干净画布，避免模板成为另一套作品对象。

### 页面列表与画布

- 页面缩略图在角标显示“封面”或“过场”；正文继续显示物理页序号。真正双页沿用中缝与页码范围提示。
- 当前舞台标签优先显示页面角色：`封面`、`过场`；正文保持现有页码标签。标签只说明当前页，不改变画布能力。
- 封面页和过场页可放入纸面图片与旁白，纸面图片可在裁切模式中按当前图片外框调整取景；首版不提供新增画格或新增对白。`interlude` 参与线上双页编排和虚拟补位，也可与另一张过场页合并为真正双页。
- 正文页沿用现有的合并为真正双页、拆分、复制、移动和删除操作。封面页只支持创建和删除；过场页支持创建、排序、复制、删除及与同类过场页的合并、拆分。

## 阅读预览与导出

- 阅读预览以页面角色决定自动分组：`story + story` 可在双页模式并排；特殊页单独占一屏；真正双页始终完整占一屏。
- 导航与进度按全部展示单元顺序前进。例如“封面 → 正文第 1 页 → 过场 → 正文第 2 页”。
- 预览不增加提示卡、跳过按钮或额外阅读模式。过场页是否承载剧情由创作者内容决定，读者按正常翻页阅读。
- 保存快照、分页 PNG、当前阅读范围下载、LCD JSON 和完整 LCD 归档都包含特殊页；现有导出渲染不因页面角色改变视觉结果。

## 三种页面角色的编辑支持

`✅` 表示首版支持；`❌` 表示首版明确不提供，而非技术上永远不能支持。除页面角色与顺序规则外，三类页面共用同一套画布和作品对象。

| 编辑或阅读能力 | `story` 正文页 | `cover` 封面页 | `interlude` 过场页 |
| --- | :---: | :---: | :---: |
| 新建空白单页 | ✅ | ✅ | ✅ |
| 插入到当前页之后 | ✅ | ❌；固定插在本话最前 | ✅ |
| 改为其他页面角色 | ❌ | ❌ | ❌ |
| 调整在阅读顺序中的位置 | ✅ | ❌；固定在本话最前 | ✅ |
| 复制当前展示单元 | ✅ | ❌；一话最多一个封面 | ✅ |
| 删除 | ✅；章节至少保留一个展示单元 | ✅ | ✅ |
| 新增和编辑画格 | ✅ | ❌ | ❌ |
| 放入纸面图片、旁白与对白 | ✅ | ✅ 图片与旁白；❌ 对白 | ✅ 图片与旁白；❌ 对白 |
| 编辑已有图片、文字、气泡、层级与裁切 | ✅ | ✅ | ✅ |
| 合并为真正双页或拆回单页 | ✅；仅相邻正文页 | ❌ | ✅；仅相邻过场页 |
| 与下一张普通单页自动双拼阅读 | ✅；仅相邻正文或过场页 | ❌ | ✅；仅相邻正文或过场页 |
| 作为真正双页独立阅读 | ✅ | ❌ | ❌ |
| 保存、预览、PNG/LCD/归档导出 | ✅ | ✅ | ✅ |
| 使用固定模板或一键生成版式 | ❌ | ❌ | ❌ |
| 作为 Agent 可直接操作的页面角色 | ❌ | ❌ | ❌ |
| 与章节列表封面图片自动同步 | 不适用 | ❌ | 不适用 |

## 开发落点

在 `PresentationUnit` 增加必填页面角色，已有和新建文档默认补为 `story`。页面创建、合并、复制、排序与校验由同一编辑 Capability 事实源管理；页面角色在创建后不可变，默认不向 Agent 开放。工作台、预览和导出只读取该字段，不自行推断“封面”或“过场”。

正式落地时需要同步更新 LCD、产品需求、编辑器体验、能力矩阵，以及跨工作台/预览/导出的一致性测试。

## 已确认的产品决定

1. 页面角色采用 `story / cover / interlude` 三项，首版不提供其他角色。
2. `cover` 至多一个，固定在一话首位。
3. 特殊页默认独立展示，只有相邻 `story` 单页自动双拼。
4. 特殊页创建后不可切换为其他页面角色。
5. 首版不提供模板；三类页面共用同一画布编辑能力。
