# 使用 MCP + Skill 与外部 Agent 创作

Lantern 的 MCP 让外部 Agent 可以创建和修改漫画、章节、资产、页面、画格、图片与文字。图片可由 Agent 自行生成，也可使用上传的 PNG、JPEG 或 WebP。

## 开始前

先启动 Lantern，并安装或同步外部 Agent 接入：

```bash
./lantern start
./lantern agent:install
```

Windows 请使用 `lantern.cmd`，安装后重启外部 Agent。Prompt 中可以直接使用漫画、章节名称或从 Lantern 复制的本地链接，无需提供内部 ID。支持显式调用 Skill 的 Agent，可在 Prompt 首行写 `$create-with-lantern`。

Agent 的修改会先写入隔离方案稿，正式工作稿不会被边做边改。完成后打开 Agent 返回的本地审查链接，在工作台中应用并保存、保留或丢弃方案。

## 从第一页开始

### 创建作品与资产

```text
$create-with-lantern
创建右到左阅读的页漫《海风经过教室》，并创建第一话“放学后的屋顶”。
建立角色资产“青木澪”（黑色齐肩短发、夏季水手服）与场景资产“临海高中旧校舍”（长走廊、推拉窗、临海）。
全篇使用清新的日式黑白页漫画风：纯黑白线稿、灰阶网点和明亮留白。为两个资产各生成一张基准图，上传并设为主要图片。
```

### 编排正文页

```text
$create-with-lantern
在《海风经过教室》第一话创作一张无对白正文页：顶部横向大格表现放学后的校园远景；下半页从右到左依次表现窗帘被风吹起，以及青木澪收拾书包、望向门外。
```

### 调整页面

```text
$create-with-lantern
让刚才页面下半部的第二格更醒目：保留顶部第一格，适度加宽第二格并收窄第三格。
保留现有图片和格间距，重新裁切受影响的图片，保持阅读顺序清晰。
```

## 继续创作

### 添加对白和旁白

```text
$create-with-lantern
在《海风经过教室》第一话的第一页，为青木澪添加一句对白，并在纸面顶部添加一句旁白。
按阅读方向安排，避开脸部和关键动作，并保留清晰的尾巴指向。
```

### 跨页大图

```text
$create-with-lantern
在当前章节直接新建真正双页：夕阳下的校园屋顶在左右纸面形成连续大图。
人物和视觉焦点避开中缝。
```

### 出格

```text
$create-with-lantern
在当前章节新建一张正文页：青木澪站在屋顶前景，海风吹起她的发梢。
让发梢越出顶部画格。
```

## 使用批注

批注适合将同一任务中的多处修改意图一次交给 Agent。每条批注可包含文字、多个作品引用和图片附件，也可以仅表达整体意见。

从工作台复制给 Agent 后，直接发送生成的内容：

```text
$create-with-lantern
请按 Skill 的标准流程完成这个 Lantern 页面中的全部待处理批注，并生成统一方案稿：<从 Lantern 复制的本地链接>
```

Agent 会读取批注及其引用、坐标和图片附件，将可统一处理的意见合并到同一方案。目标已变化或缺失时会说明原因；方案审查和批注的解决、搁置仍由你在 Lantern 中决定。
