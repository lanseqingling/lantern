# 编辑器体验

## 1. 文档定位

本文定义 Lantern AI 工作台的空间结构、视觉语言、对象反馈、直接编辑、图片使用、候选确认和阅读预览规则。产品范围见[产品需求](./prd.md)，作品对象归属见[LCD](./lcd.md)。

工作台遵循本文的交互与视觉规则。本文不描述组件内部状态、API 或模型任务实现。

### 界面文案

产品预置且用户可见的固定文字以 `ui-copy` 为唯一事实源，包括组件名称、动作、状态、Toast、系统提示、弹窗说明、表单标签与占位文字、选项名称、页面元信息和无障碍标签；即使只在一个位置出现，也不得直接裸写在组件、Hook 或前端工具函数中。文案按“领域 → 场景或组件 → 语义名称”分类；同一分类过大时继续使用语义前缀或下一级分类，禁止使用序号、句子片段或仅表达语法位置的键名。需要变量时定义具名插值函数，领域枚举的显示名称也从同一文案库派生。

黑底白字、短暂出现的反馈统一归入 `uiCopy.toast`，再按页面领域和操作流程分类；Toast 位于顶部或底部属于组件布局，不进入文案键名。页面内持续状态、表单错误和弹窗内容分别归入对应的 `status`、`error` 和 `dialog`，不因文字语气相近而与 Toast 混用。

用户创作内容、来自接口或数据库的作品数据、内部标识、服务端日志、API 错误码，以及不会展示给用户的 Agent 系统提示与能力指令不属于界面文案库。服务端向界面传递可恢复错误时优先返回稳定错误码，由界面映射为文案；服务端直接返回并展示给用户的固定提示也必须使用明确归类的文案键。

文案治理不依赖静态检查器。任何前端改动在交付前都必须语义审阅本次涉及的 TS/TSX 文件，检查 JSX 文本、组件属性、Toast、错误回退、弹窗、表单、ARIA、页面元信息和动态拼接；专项文案治理或全量 Review 必须逐文件扫描 `apps/web/app` 下的全部 TS/TSX 源码。搜索或脚本只能辅助定位，不能作为“没有遗漏”的完成依据。

新增或调整文案时沿用相邻界面的术语、语气和标点，使用用户能直接理解和执行的表达，避免内部实现术语、含糊的未来承诺、过度具体的示例和同义词漂移。Toast 保持简短且不加句末句号，完整说明文字自然使用标点。

## 2. 交互原则

### 一个持续创作空间

角色、场景、分镜、编排、单格精修和阅读检查不拆成强制向导。用户在一话工作台中围绕同一份工作稿移动焦点，必要时进入漫画首页、资产空间或阅读预览。

产品预览首页 `/` 保持单屏；向下滚动、上滑或选择“开始创作”后，以连续的离场和入场动效直接进入漫画首页 `/workspace`，不展示中间页面或加载状态。漫画首页位于页面顶部时，连续向上滚动或下滑达到返回阈值，或选择左上角 Lantern 标识，会以同一方式返回产品预览首页。用户启用减少动态效果时直接完成跳转。

漫画首页、漫画详情、工作台、阅读预览、资产空间和全局设置使用同一套克制的内容转场：前进时旧内容轻微上移、目标内容从下方进入，返回时反向执行；固定页角控件较多的全局设置只淡入淡出。工作台与阅读预览先完成同一话的模式切换，再以该转场衔接目标页面；短暂路由加载的占位提示延迟出现，加载、保存和删除不等待转场。

漫画与每一话各自保留“创作中”或“已完成”的创作阶段；阶段只表达个人创作进度，不表示对外发布。漫画首页的每张漫画卡片显示漫画阶段，保存漫画或章节设置后会确认当前阶段；示例漫画只显示其示例标识，漫画阶段不可修改。章节列表在梗概前显示本话阶段，且本话阶段优先决定默认入口：创作中进入工作台，已完成进入阅读预览。更多菜单始终提供“进入工作台”和“阅读预览”，方便显式覆盖默认入口；点击菜单外部会关闭菜单，章节菜单会在底部空间不足时向上展开；预览仍只读取已保存快照。

页漫的漫画设置显示新建一话的默认阅读顺序；当前使用从左到右，从右到左作为不可选项显示。已有一话继续使用其 LCD 中保存的实际阅读顺序。条漫沿纵向连续阅读，不显示该设置。

### 漫画内容第一

漫画纸张和画格始终是视觉主体。图片、抽屉、工具条、对话和候选以辅助层进入同一空间，不遮蔽当前编辑对象，不把任务过程做成画布作品对象。

### 直接操作与 AI 协作分工

- 选择、移动、缩放、裁切、文字和气泡调整等确定性操作直接完成，并进入可撤销工作稿。
- 需要生成、自然语言理解、结构调整或多对象处理的动作进入右侧对话，并先产生候选。
- 人类操作与 AI 协作使用同一对象语义、影响范围、校验和回退方式。

### 按风险显示信息

普通直接编辑只显示当前对象与必要工具。AI 准备行动或产出候选时，用户需要看懂焦点、意图、关键参考和影响范围。跨格、整页、整话、格式切换和覆盖已确认内容的动作必须额外确认。

## 3. 工作台结构

工作台以全屏点阵画布为底层，主要区域均为悬浮界面：

| 区域 | 主要内容 | 交互职责 |
|---|---|---|
| 顶部导航 | 左侧返回漫画，右侧显示当前漫画/一话和工作稿摘要 | 右侧摘要卡打开项目菜单，用于进入资产空间、保存、回到上次保存、预览、导入完整 LCD 资源和打开开发上下文。创作空间首页 `/workspace` 的 Lantern 标识进入产品预览首页 `/`。 |
| 左侧创作空间 | 资产、分镜和漫画页或滚动段 | 定位素材与作品结构，不承载任务目录。 |
| 中央漫画舞台 | 当前页面、画格、格内元素、图片与候选预览 | 直接选择、编辑、比较和检查作品。 |
| 右侧对话 | 会话、消息、追问、任务事件、候选和输入区 | 处理需要理解、生成或确认的协作。 |
| 底部创作工具 | 选择、平移、页面或设备视区查看、上传、编排、旁白、Undo/Redo、AI 模式标识与预览 | 提供高频直接动作和模式入口；AI 图标仅表示当前创作模式，不写入对话内容；旁白进入跟随指针的放置模式，对白从纸面或画格的管理菜单新增。 |

左右抽屉可以收起。抽屉覆盖画布视口，不改变 LCD 坐标，也不改变图片在画布世界中的位置。画布平移只移动画布世界层；顶部导航、抽屉、对话和工具保持固定屏幕位置，工作台不发生页面滚动或回弹。

首次进入工作台时，轻量导览直接指向创作空间、漫画页、核心画布工具和 Agent 输入区，完成全部步骤后进入工作台。导览只操作工作台辅助界面，不修改作品、选择、画布位置或对话；完成后可以随时从右上角帮助入口重新播放。

右上角全局设置进入独立设置页，承接模型 API、本地运行信息和应用更新。对话、生图和视觉理解使用各自可折叠、独立保存的配置卡，展开后先显示 Provider、模型、API 地址和脱敏 Key，进入修改状态后才显示输入组件；选项来自统一 Provider 目录，不在界面写死厂商。Key 不回传到浏览器，保存后新模型请求立即生效。缺少所需 Key 时，AI 入口提示前往设置，普通画布编辑继续可用。Lantern 启动后在后台检查最新正式 Release，结果保留 30 分钟，设置页可手动刷新；新版本直接替换当前版本行并与下载图标组成一个入口。发行包安装可从该入口下载、校验、替换服务文件并自动重启，更新期间显示下载与安装进度，刷新设置页后继续展示当前进度；开发源码目录只打开 Release，不自动覆盖。

### 左侧创作空间

左侧上半区在“资产”和“分镜”之间切换：

- 资产：显示当前创作空间可用素材，每项使用小型圆角方形缩略图，并在名称前固定显示人、景、物、风、草或图的类型标签；单击列表项只选中，双击才在当前页面的内置图片查看器中打开主图。列表资产与其画布图片共享同一个选择，任一时刻只保留一个逻辑选中项；切换列表资产、画布图片或漫画对象会替换旧选择。更多菜单可定位到画布、添加到画布、引用到对话、改名或移除列表项。右上角带文件夹图标的“资产空间”进入完整资产空间，旁边的 `+` 直接上传图片资产，并同时添加到左侧列表和画布图片层。
- 分镜：按画格组织单格画面。选择分镜条目会定位对应画格；没有主分镜的画格可以就地创建并绑定。

下半区固定显示作品缩略图、名称、物理页码范围、当前位置、画格数和新增入口。页漫的新增入口提供正文页、封面页和过场页：正文页默认追加到末尾，过场页插在当前页之后，封面页至多一个且固定插在本话最前；封面已存在时入口定位到它。章节设置上传封面会创建该封面页并以自适应填满方式放入背景图；章节卡片读取整张封面页的合成画面。封面上的图片可继续移动、缩放、裁切或叠加，新增图片默认铺满纸面。特殊页创建后不可改为其他角色，封面不可复制或移动，过场页可复制、排序与删除。缩略图和舞台标签显示“封面”或“过场”，正文继续显示物理页序号。封面页和过场页可新增纸面图片与旁白，但暂不支持新增画格或对白。页面更多菜单可在当前单页或真双页展示单元之前、之后插入一张空白正文页，并统一重排物理页码。页面或滚动段的更多菜单可复制当前展示单元并紧随其后插入，或上移、下移一个展示单元；复制会保留画格、对象和资产引用，并为对白、分镜及内部对象生成独立 ID。条漫称为“滚动段”，新增时从 `4:3`、`1:1`、`3:4`、`2:3`、`9:16`、`9:20` 中选择宽高比。相邻且同为正文或同为过场页的单页可合并为真正双页；不同角色和封面不能合并。普通滚动段可与下一段合并为复合滚动段。两侧叠格策略不同时不阻止合并，合并结果采用“允许叠格”以保留已有编排。列表使用中缝和编号范围表示不可拆开的展示单元。合并、拆分和删除都需要二次确认，一级入口保持中性；拆分按对象的实际几何范围判断，只有跨越分隔线的对象才会阻塞，已完整移至单侧的跨页或跨段对象在拆分时自动转为该侧普通纸面对象。

### 中央漫画舞台

- 聚焦选择模式用于选择和编辑漫画对象；自由画布模式只移动视口。
- 工作台与阅读预览进入时默认单页查看；底部工具栏的单双页按钮切换双页阅读编排。选择写入本话 Project 的工作台设置，不写入漫画内容、快照或导出：封面独立且不参与计算；其后的第一张正文或过场页独立，随后相邻的正文、过场页成对收拢为带外圈的子卡片。被真正双页、封面或章节结尾切断的普通单页会出现虚拟补位页，右侧 `+` 可把它变成实际空白页，也可将已有页面拖入该位置；虚拟补位页不会写入作品。真正双页由作品结构明确创建，在两种模式下都完整显示；双页模式遇到真正双页时，其前后落单页自动单独显示。自动翻页点不改变画布或单页导出，也不限制合并下一页；双页模式中新增、插入、删除、合并或移动页面后，所有分组外框以黄色短暂提示重算，初始加载和其他操作不提示。页漫在窗口变窄或变矮时，按左右已展开面板和底部工具栏之外的中央可用区域等比缩放，不遮挡辅助界面。自由画布模式复用预览翻页交互：鼠标进入纸张左半区显示左三角并前翻，进入右半区显示右三角并后翻；双页画面自然按左右纸张区分，单页画面按纸张中线区分。条漫不启用点击翻页。
- 真正双页空白处可以放入一个跨页图片，也可以把画格设为跨页格、把格内/破格/纸面气泡设为跨页对白；跨页格的主图仍保持格内裁切，跨页气泡转为 Unit 锚定且使用“跨页泡 01”短编号。复合滚动段可以放入跨段图片。只有直接归属纸面的图片可以转换为跨页或跨段图片，格内或破格图片必须先转为纸面图片。跨页与跨段均可取消并归回单一纸面，转换不复制资源或对象实例。
- 条漫聚焦模式保持各滚动段连续渲染，切换段时平滑滚动到目标位置。滚动期间短暂显示不可操作的位置视图，停止后自动淡出。
- 条漫可循环切换关闭、手机 `9:16`、长屏手机 `9:20` 和平板 `3:4` 设备视区。取景框固定在工作台可视区中央，内容从框内滚过；空间不足时取景框与条漫画布同步等比缩小。该状态只辅助编排，不写入作品、快照或导出。
- 图片可以在画布中移动、缩放和调整层级，但不会进入漫画成稿。
- 候选预览只把目标结果临时投影到对应对象，并允许切换候选与工作稿；它不创建 revision，也不自动改变当前展示单元。
- 选择框、辅助线、对象工具条和编辑浮层属于交互层，预览与导出时隐藏。

### 右侧对话

右侧保留可回看的长对话。每个会话属于当前 Project；切换会话只切换消息、未应用候选和当前任务上下文，不切换作品工作稿。

会话抽屉支持新建、切换、重命名和删除。删除会话不删除已经应用的作品内容。

工作台 URL 保存当前会话 ID 和当前展示单元 ID，刷新后恢复到同一对话与同一漫画页或滚动段。页面定位使用稳定的 PresentationUnit ID，不使用会因插入、删除或排序而变化的数字页码；它属于工作台 UI 定位状态，不进入 LCD、WorkingRevision 或 SavedSnapshot。离线演示状态仍保存在浏览器 localStorage。

首次打开工作台、刷新或切换会话时，对话定位到最新消息；用户主动折叠再展开对话时保留原阅读位置。发送消息后，Agent 在同一条回复中先显示轻量思考状态，再流式呈现正文，不为每句话重复弹出全局提示。图片附件可以进入内置查看器。

显式引用显示在用户消息正文上方，使用较小的灰色文字，多个引用以空格分隔，不打印 Markdown 的 `>` 字符。发送成功后同步清空输入区引用和本轮附件；已发送消息仍保留当时的引用事实。

输入区包含：

- 文字输入。
- 本轮图片附件。
- 当前创作意图快捷选择。
- 当前对象或显式对象引用。
- 发送或停止当前任务。

同一会话同一时间只运行一个任务。任务运行时旧作品保持可见，用户可以停止任务；完成后仍需通过候选确认进入作品。

任务运行时保留未发送草稿并禁用重复发送。停止入口使用单一的 `X` 图标，点击后先确认取消；任务状态只显示可验证的上下文准备、排队、模型生成、校验和结果保存等事实，不展示思维链、虚构步骤或伪精度百分比。失败重试继续使用原失败卡片，不能为同一次请求重复追加失败卡。刷新或切回会话后，从服务端恢复 Message、Task 和 Candidate 的实际状态。

## 4. 作品层、图片层和协作层

### 漫画作品层

漫画层对应 LCD 的 `PresentationUnit → PageSurface → Frame → Layer → Element`：

- PresentationUnit：一次共同阅读和编排的页面、双页或条漫段。
- Frame：画格容器，可移动、缩放、调整样式并绑定单格画面。
- ArtElement：格内成稿或多层画面；取景只修改 crop。
- Dialogue / BalloonElement：对白语义与气泡视觉实例。
- Unit Overlay：破框、跨格和跨页对象。

直接编辑必须作用于正确对象层级。移动画格不能改写格内坐标，调整取景不能移动 Frame，图片也不能通过拖拽直接变成成稿。

### 画布图片层

画布图片用于对照和显式引用，不进入 LCD、阅读预览或导出。

- 上传到画布的图片创建可持久化的素材与摆放关系。
- 图片可以移动、缩放、调整层级、改名、保存到漫画资产或从画布移除。
- 保存为资产后，画布摆放与来源 Asset 仍是两个关系；移除摆放不删除 Asset。
- 修改图片内容创建新 AssetVersion，移动、缩放或改显示名不创建图片版本。
- 将图片真正放入成稿时，在目标 Frame 图层或 Unit Overlay 创建元素并固定引用 AssetVersion。

对话输入区上传只作为本轮消息附件，不自动创建画布图片或漫画资产。

### 候选与任务

任务事件只显示在对话中。候选可以显示在消息或画布预览层，但在用户应用前不属于工作稿。

Candidate 必须显示：

- 结果标题和简短变更摘要。
- 作用范围或目标对象。
- 可用、已应用、已撤回、已丢弃或已过期状态。
- 当前结果实际支持的预览、应用、保存、丢弃或查看动作；不显示未接入的占位入口。

可用候选默认展开且不能手动折叠。已应用或已保存结果默认展开；已丢弃和已过期结果默认折叠为摘要，并允许重新展开查看。过期候选不显示操作按钮。Candidate 自身不提供“删除本次应用”一类局部回退入口，已应用结果统一通过工作台 Undo/Redo 管理。

## 5. 选择、焦点和编辑状态

### 选择规则

- 点击画格选择 Frame；点击格内图片选择 ArtElement；点击气泡选择 BalloonElement；点击画布图片选择摆放对象。
- 选中对象后，只显示该对象可执行的直接动作。
- 左键选择显示对象编辑工具栏，承载移动、缩放、裁切、对白和单格画面等直接编辑；右键命中最具体的页面对象并只显示对象管理菜单，承载新增、复制、适用对象的更换和删除。对象编辑工具栏的“更多”打开同一份管理菜单。
- 右键纸张空白处显示纸张管理菜单并可在指针附近新增画格；右键图片和气泡不得退回选择其父画格。
- 格内、破格、纸面、跨页和跨段图片的管理菜单统一通过“更多选项”查看或下载当前固定资源版本，或把图片的来源资产添加到左侧资产列表；来源已在列表中时显示已添加。移除过的列表项可以从仍在作品中的图片恢复；来源资产曾从资产空间删除时，同时恢复其资产家族，确保后续仍可使用。恢复不复制图片资源，也不改变作品对象的归属。画格生成图加入左侧列表后仍需由用户执行“保存为资产”并选择正式类型，完成后才显示为“已关联资产”并进入资产空间。
- 内置图片查看器由左侧资产项或画布图片主体双击、任务 Candidate 的生成图、纸面图片“更多选项”、资产空间图片详情右键菜单或单击详情大图打开。图片单击只改变选择，双击才进入查看器；多选模式不打开查看器。画布入口按当前摆放顺序浏览同一画布的其他图片，资产空间入口按该资产的图片序列浏览。图片居中显示，底部半透明工具栏和鼠标滚轮均以较小步幅缩放，并提供 `1:1` 原始尺寸与适应窗口切换；放大后不出现滚动条，图片可以拖动定位并允许边缘移出屏幕，切换图片或显示模式时重新居中。其他单图入口不虚构相邻图片。
- 左键双击画格、气泡或旁白进入移动模式，再次左键双击同一对象退出；图片双击进入图片查看器。连续两次右键点击支持裁切的画格或格内图片进入裁切模式，再次执行退出。工具栏中的明确动作与手势共用同一编辑状态。
- 画格进入裁切模式后，四个角显示青色编辑点。拖动超过起始阈值后自动锁定横向或纵向，只改变一个角在该轴上的位置；向外拖动可以扩展画格包围盒。单次拖拽只产生一次撤销，重置画格角度恢复矩形。
- 移动画格、从任一角缩放画格，或移动和从右下角缩放纸面图片、破格图片时，只有同向的同名边界进入很小的屏幕距离阈值才吸附，例如左边对左边、右边对右边、下边对下边；命中时显示贯穿当前纸张且位于所有对象上方的青色虚拟延伸线，移出阈值或结束拖拽后立即隐藏。不同名边界不互相吸附。
- 每个 `PageSurface` 由编辑器按纸面短边的 `5%` 派生唯一内容安全框，不写入作品协议。拖动或从任一角缩放普通画格时显示整张纸面的青色回字型提示线；画格对应外边靠近安全框时按同一屏幕距离阈值吸附。出血格仍可越过安全框延伸至页边，跨页格不受单一纸面安全框约束；真正双页分别显示左右纸面的安全框。
- 四角编辑接近水平或垂直时吸附为正交边，并显示贯穿当前纸张的青色虚拟延伸线。除此之外，左右相邻画格比较相对的左右边，上下相邻画格比较相对的上下边；被编辑顶点使当前边进入小距离阈值时，当前边吸附为与最近邻格的参考边平行。邻格参考边显示局部青色虚线，当前画格命中的平行边显示青色实线；正交与邻格平行同时命中时采用指针修正距离更小的一项。
- 点击空白区退出对象编辑；打开一个浮动菜单时关闭同级其他菜单。
- 多选模式明确区分漫画对象与画布图片对象，只有允许的组才能批量移动或移除。

### 直接编辑

| 用户动作 | 作品变化 |
|---|---|
| 拖动画格 | 只修改 Frame 位置；靠近其他画格的同名边界或所属纸面的内容安全框时吸附。 |
| 缩放画格 | 修改 Frame geometry，不改格内局部坐标；最小可缩至 `40 × 32` 画布单位以支持窄格和短格，任一角的移动边靠近其他画格同名边界或所属纸面的内容安全框时吸附。 |
| 编辑画格 | 编辑面板分为独立的分镜条目与画格区域；分镜条目仍编辑标题和描述，画格区域可按 `0.5` 步进直接修改边框粗细并支持 `1.5`，也可分别把上、右、下、左边延伸至所属纸面页边，不要求画格先绑定分镜。 |
| 出血格 | 画格右键布局菜单通过“延伸至页边”二级菜单选择方向，编辑面板保留四边开关。开启后画格自动贴至对应页边、隐藏该边框并保持内容裁切；未开启的边仍显示边框。普通双页画格只作用于所属单页，跨页格作用于完整双页。 |
| 拖动或缩放图片 | 裁切模式固定当前图片外框，格内与纸面图片都通过拖动或滚轮缩放修改 crop；纸面图片的外框即裁切边界。移动模式下纸面与破格图片修改局部 transform，并在移动或缩放边界靠近其他画格同名边界时按虚拟延伸线吸附。裁切取景不吸附。 |
| 裁切模式滚轮缩放格内图片 | 以指针位置为中心等比修改 crop；缩小上限保证图片投影的宽、高都不小于 Frame，不露出空白边。 |
| 裁切模式拖动画格角点 | 自动识别横向或纵向并锁定轴，只调整一个角和相邻边的角度；接近水平或垂直时正交吸附并显示整页虚拟线，边框、遮罩与格内内容按同一四边形实时预览。角点和缩放点进入独立的临时顶层交互层，不被破格图片或对象编号遮挡，也不改变作品对象的视觉层级。 |
| 在纸张空白处新增画格 | 创建带标准画面层和对白层的矩形 Frame，并按页面位置进入阅读顺序。 |
| 放入、更换或移除格内图片 | 创建、替换或移除当前 Frame 的主 ArtElement；来源资产及其他引用不变。 |
| 从图片选择卡放入格内图片 | 当前展示单元中未绑定画格的纸面、跨页或跨段图片排在前部，画布图片不区分资产类型并随后显示，最后读取左侧资产列表中的图片资产；画布摆放与素材列表指向同一资源版本时只显示画布项。选择纸面图片会把原对象收回画格并从纸面移除；选择画布图片或资产只复用固定资源版本，原画布图片保持不变。候选以固定 `3 × 3` 网格显示，更多项目使用轻量滚动条；上传入口只位于左侧资产栏。 |
| 新增或删除对白 | 以一个复合能力创建或移除 Dialogue 与 BalloonElement。 |
| 新增纸面图片或对白 | 在右键位置创建 Unit 锚定的 `page_content` 覆盖元素，不依赖画格。 |
| 新增旁白 | 底部 `T` 进入一次性放置模式，在点击位置创建 Unit 锚定的 `narration` TextElement；点击纸面外或按 Esc 取消。 |
| 编辑旁白 | 透明背景，默认 24 号黑字与清晰白描边；横排默认约 6 字 × 2 行，竖排默认约 2 列 × 6 字，列内从上到下、列间从右到左，数字和英文逐字正立。可编辑文字和字号、移动、拉伸换行区域、切换横竖排、旋转、复制或删除；竖排宽度最小可缩至一列文字，横排保持原最小宽度。裁切入口只提供右下角旋转点，切换方向时保留用户已经放大的尺寸，不支持图像裁切和层级调整。 |
| 设为破格、转为纸面对象或收回画格 | 在 Frame 图层、Frame 锚定 Overlay 与 Unit 锚定 Overlay 间迁移同一对象，保持 ID 和视觉位置。 |
| 允许或取消叠格 | 显式切换展示单元的重叠策略；允许时当前画格连同格内内容置于顶层，之后仍可独立调整画格视觉层级。 |
| 编辑单格画面 | 创建或更新当前 Frame 的 primary StoryboardBeat。 |
| 编辑对白 | 修改 Dialogue 内容，并可调整气泡字号和边框粗细；边框按 `0.5` 步进并支持 `1.5`，横排按宽度自动换行，竖排按高度自动换列。 |
| 调整气泡 | 修改气泡形状、横竖排、位置、尺寸或尾巴；可选择四角不等距切割的无尾八边形“切角对白”，切角使用基础参数的两倍视觉幅度，每次主动切换到该样式都会生成不同轮廓，生成后保持稳定；宽度最小可缩至横排每行一个字或竖排一列字，矩形对白同样适用；裁切入口只提供右下角旋转点，不重生成画面。 |
| 移动画布图片 | 只修改画布摆放。 |

### 对象归属与跨层编辑

- 选中作品对象时在管理菜单显示 `格内`、`破格`、`纸面`或`跨页`状态；状态来自 LCD，不由视觉位置猜测。
- 新画格默认不能重叠，新格内元素默认不能拖出画格；普通拖动只修改当前层的位置。
- 对象到达画格边界时显示阻力和可投放目标，不自动改变归属。新增或拖放时高亮画格与纸面，落入画格创建格内对象，落在纸面空白创建 Unit 对象。
- 右键和对象工具栏“更多”共用跨层动作：设为破格、收回画格、转为纸面对象、关联到画格、调整前后层级、设为叠格或取消叠格。只显示当前对象适用的动作；“设为破格”保留画格归属，“转为纸面对象”解除画格归属。
- 跨层转换保持对象 ID，并作为一次可撤销 ChangeSet 提交。气泡、文字和效果保持视觉位置；直接执行“收回画格”时，图片只能进入没有格内主图的 Frame。通过格内图片选择卡选取纸面图片时，允许在同一 ChangeSet 中移除原格内主图并把所选纸面对象收回画格。成功收回时恢复为铺满画格的元素容器并保留 crop，避免破格位移留下不可编辑空区。视觉层级变化不自动改变画格或文字阅读顺序。
- 画格、对白和覆盖层图片编号位于独立的顶层交互层，不随作品视觉层级被遮挡；相邻编号自动错开以保持每个编号都可点击。编号默认黑底，选中后统一为青底；破格图片和纸面图片统一使用 `图 01` 形式，选择标签不显示资产名称。
- 纸面、破格、跨页和跨段图片不提供更换动作；需要新内容时移除原对象，再从对应纸面管理菜单放入新的图片资产。只有格内主图可以直接更换。

一次连续拖拽在提交时只形成一个 Undo 单位。连续确定性编辑按 revision 顺序本地应用并串行持久化，后一次响应不得覆盖前一次已确认结果。Undo / Redo 自身也形成持久化 ChangeSet，并且每次只恢复一个历史单位；未应用候选和对话消息不进入作品撤销历史。全局菜单的“回到上次保存”把最近 SavedSnapshot 及其分镜版本恢复为一个新的可撤销工作稿 revision，不修改原快照。

## 6. 意图、作用范围和引用

输入区的意图选择是快捷提示，不是强制模式。系统结合自然语言、当前选择和显式引用判断本次协作。

常用作用范围：

| 范围 | 含义 |
|---|---|
| 仅图片 | 只创建或维护画布图片，不修改作品。 |
| 当前元素 | 只影响选中的图片、文字或气泡。 |
| 当前画格 | 只影响当前 Frame 和其单格画面。 |
| 当前页面 | 只影响当前 PresentationUnit。 |
| 从这里往下 | 只追加当前锚点之后的内容。 |
| 整话 | 影响多个页面或全章结构，需要独立确认。 |

显式引用可以来自漫画格、气泡、画布图片和漫画资产。发送时保存对象 ID 与固定 versionId；后续资产更新不能改变旧消息的引用。系统可以自动补充高相关上下文，但关键自动参考应可解释，不在输入框常驻堆叠。

## 7. 典型流程

### 调整当前格

```text
选择画格或格内图片
  → 直接调整 Frame / crop / 单格描述
  或输入自然语言要求
  → 查看只影响当前格的图片候选
  → 预览、应用或丢弃
```

### 创建并使用图片资产

```text
上传图片到画布或从资产空间导入
  → 在画布对照、改名和摆放
  → 保存为漫画资产
  → 引用到当前对话或目标画格
```

资产空间也可以直接创建角色、场景、道具或参考图片资产，不依赖进入某一话工作台。创建表单默认选择角色，填写类型、名称和描述；可选图片在资产创建后作为首张图片上传，之后仍可在详情中继续管理图片。表单中的 AI 按钮会带着已填写的类型、名称和描述进入最近一话的工作台对话；对话输入框默认保持两行，从第三行起自动增高，最多显示八行，超出内容使用内嵌滚动条。资产详情与图片查看器固定在视口中央，不随资产空间的页面滚动偏移。

### 预览、保存与返回

```text
保存工作稿为快照
  → 进入阅读预览
  → 隐藏画布图片与编辑控件
  → 按作品阅读顺序查看
  → 返回对应页面继续编辑
```

预览只读取最近保存快照中的 LCD 与固定资源版本，不读取当前工作稿、对话、图片摆放或临时选择。下载菜单按当前画面实际显示的阅读范围保存 PNG：单页画面下载单页，真双页或双页预览中并排显示的两张普通页下载为一张双页图；“下载本话图片（ZIP）”按阅读顺序打包本话的成稿 PNG，普通纸面逐页保存，作品中的合成双页保存为一张完整图片，不受预览单双页模式影响；“下载 LCD 文件”保存不含临时资源地址的独立 JSON，其下方的“下载完整 LCD 资源”保存包含 LCD、分镜条目、资源清单和全部已引用图片文件的一话 ZIP 归档。

左上项目菜单的“导入完整 LCD 资源”只接受完整 ZIP 归档。用户选择文件后需要确认覆盖当前一话；解析和完整校验成功后，工作台切换到导入的一话内容并清空本地 Undo / Redo 记录，导入内容同时成为新的保存版本。校验失败保持当前画布不变。

## 8. 响应、动效与可访问性

- 桌面端优先保证中央漫画可读、左右抽屉可收起和浮层不遮挡当前对象。
- 关键状态不能只依靠颜色；选中、候选、失败、过期和禁用需要文字、图标或形状辅助。
- 所有图标按钮提供可读名称，菜单与对话支持键盘焦点和 Escape 关闭。
- 拖拽之外提供按钮或表单完成关键操作。
- 动效只解释焦点、抽屉、候选比较和模式变化，不能延迟保存、应用或路由反馈。
- `prefers-reduced-motion` 下取消非必要位移和缩放。

## 9. 视觉语言

### 漫画内容第一

纸张、画格、成稿和对白是最高视觉层级。侧栏、对话、候选和工具围绕内容出现，不把工作台做成后台控制台、流程图编辑器或传统专业绘图软件。

### 轻、圆润、有空间感

界面使用冷白稿纸、低对比点阵、半透明浮层、柔和阴影和较大圆角。层级主要依靠空间、明度和轻阴影，不依赖粗边框或大面积高饱和色块。

### 页面外壳与信息密度

创作空间首页、漫画首页、资产空间和全局设置共用冷白点阵底、低强度青色与琥珀环境光和同一组悬浮控件；画布保留中性的无光晕工作背景，避免干扰漫画内容。除首页展示外，内容区只使用宽版与窄版两档：漫画和资产使用宽版承载并列信息，设置使用窄版聚焦配置，页面不各自发明第三种主容器宽度。

返回与全局设置等跨页面动作固定在顶部安全区，使用同尺寸的圆角浅色图标按钮；它们只承担导航和全局动作。页面标题独立置于内容流中，必要时用深青底白色图标说明页面领域，不与返回控件或产品标识拼成大标题卡片。资产和漫画等需要浏览多项内容的页面可以使用轻量卡片；设置页不使用包住全部内容的大卡片，模型配置由可展开的小卡片承载，本地运行信息以紧凑行列表呈现。

### 颜色语义

- 青色：选择、焦点、引用、结构辅助、当前工具和可编辑边界。
- 琥珀：等待确认、生成推进、关键候选和需要用户注意的下一步。
- 红色：失败、阻塞性错误和不可逆风险的二次确认面。一级菜单中的删除或移除是进入确认流程的普通入口，使用中性文字与图标。

普通选中不使用琥珀，避免把所有操作都表现为待确认。状态不能只依赖颜色，必须同时提供文字、图标、边框或形状表达。

## 10. Visual Tokens

以下视觉 token 定义工作台的稳定颜色语义，具体界面应保持一致使用。

### Color

| Token | 定义值 | 用途 |
|---|---:|---|
| Canvas | `#f6f8f9` | 应用和画布背景。 |
| Paper | `#ffffff` | 漫画纸张、卡片和高层浮层。 |
| Ink | `#172026` | 主文字和高对比图标。 |
| Muted | `#68747c` | 次级文字、说明和停用信息。 |
| Cyan | `#64c8c8` | 选中、结构和主要交互提示。 |
| Cyan Deep | `#247f82` | 青色文字、图标与强调边界。 |
| Cyan Soft | `#e8f8f8` | 青色浅背景和 hover。 |
| Amber | `#f2b84b` | 候选、推进和注意状态。 |
| Amber Soft | `#fff3cf` | 等待确认的浅背景。 |
| Danger | `#d85b5b` | 失败、阻塞性错误和危险动作的二次确认背景；不用于一级操作入口。 |

边框使用 Ink 或 Cyan 的低透明度变体。Glass surface 使用接近白色的透明背景和 backdrop blur；正文保持足够对比度。

### Typography

默认字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
```

- 页面与对话标题紧凑、较高字重，避免超大营销字号进入工作台。
- 正文以可读性为先，保持舒适行高。
- 标签与状态可以使用小字号和高字重，但必须有可读文案。
- 代码与调试内容使用等宽字体，不与普通用户界面混用。

### Radius、Shadow 与 Spacing

- 纸张使用小圆角；输入、按钮和工具使用中圆角或胶囊形；卡片、抽屉和对话使用大圆角。
- 阴影只用于悬浮层级，不给每个列表项增加独立重阴影。
- 通用间距以 4 / 8 / 12 / 16 / 24 / 32 为基础，密集工具组可以使用更小内部间距。

### Motion

- hover、focus、菜单和图标状态使用约 140ms 的快速反馈。
- 抽屉、候选和焦点切换使用约 180–240ms 的过渡。
- 路由、保存、应用和停止任务先立即反馈，再执行非必要动效。
- 动效不改变 LCD 坐标，也不制造作品已经修改的错觉。

## 11. 通用界面原语

### Floating Surface

用于项目菜单、抽屉、对话、对象检查器和候选工具条。统一使用浅色或半透明背景、细边框、大圆角和柔和阴影；相同层级共享 padding、菜单分区和关闭方式。

### Button

- Primary：应用、保存、创建等明确推进动作。
- Secondary：预览、继续修改和普通工具。
- Ghost / Icon：高频画布工具和菜单入口。
- Danger：只用于删除、丢弃或明确风险动作的二次确认。一级操作入口保持中性，触发后再由确认层说明影响范围并承接风险表达。

图标按钮必须有可读名称。禁用按钮降低强调，同时保留禁用原因。

### Menu

- 按导航、对象操作和危险操作分区。
- 使用固定 UI 尺度，不随对象或画布缩放。
- 同级只允许一个菜单打开；点击外部或 Escape 关闭。
- 危险动作与普通动作之间有清楚分隔。

### Drawer

- 左侧创作空间和右侧对话都可以收起与恢复。
- 抽屉内部滚动不移动画布。
- 抽屉开合不改变作品或画布图片对象坐标。
- 收起后在可见视区保留恢复入口。

### Delete Confirmation

- 删除资产、资产图片、纸面元素、漫画页、滚动段、一话或漫画使用同一个居中二次确认组件；一级菜单保持中性，破坏性语义只在二次确认中强调。
- 一级入口保持中性；确认层统一显示删除图标、影响范围、取消和确认动作。
- 禁止删除时仍显示原因，并停用确认动作。

### Custom Select

- 触发器显示当前值和展开状态。
- 选项支持标题、简短说明和禁用状态。
- 菜单避免超出视口，支持键盘导航与 Escape。
- 不将互斥选项做成长期占据画面的模式 chip。

### Object Toolbar / Inspector

- 靠近当前选择，并避开相邻画格与左右抽屉。
- 只显示当前对象适用的动作。
- 直接编辑优先使用短工具条；需要文字或属性输入时打开轻量检查器。
- 管理动作使用带文字的上下文菜单；右键和对象工具栏“更多”共用同一入口，不复制动作定义。
- 对象管理菜单按内容、归属、画格布局、层级、对象和删除的语义顺序排列，只显示当前对象适用的分组；组间只使用分割线，不显示分组小标题，视觉前后顺序、叠格策略和删除各自独立成组，删除始终位于最底部。
- 对象管理菜单标题只显示对象图标、类型和适用对象的两位编号，例如 `画格 01`、`对白 01`、`旁白 01`、`Page 01` 或 `滚动段 01`，不重复显示“对象管理”副标题。旁白编号按当前展示单元派生，只在右键管理、编辑或引用中显示，不在纸面对象角落显示；竖排旁白中的汉字、数字和英文字符都逐字正立。
- 拖拽期间不反复重排工具条，提交后再更新位置。

### Candidate Card / Compare Toolbar

- 显示标题、范围、简短变更摘要和状态。
- 按结果类型提供预览、应用或丢弃；未接入的动作不显示占位入口。
- 候选预览不能让用户误以为结果已经写入作品。
- 过期候选说明状态并移除写入入口。
- 单格图片候选完成时，如果目标仍在当前展示单元，则自动进入候选预览；否则保持候选可用，不自动翻页。用户主动点击“预览”时也直接进入同一预览状态。
- 单格图片预览只替换目标画格的临时投影，并以黄色边框标记目标，不显示移动或缩放编辑点。预览期间在工作台底部最高层显示横向工具条，包含黄色“应用”、带图标的“预览/还原”二态切换和带图标的“取消”；取消只退出预览，不丢弃 Candidate。
- 预览画格、底部工具条和最终应用必须绑定同一个 Candidate ID 与目标对象，不能因列表刷新或其他任务状态变化串联到另一张卡片。

### Composer

- 文本输入是视觉主体，显式引用与图片附件以可移除标签显示。
- 意图选择、引用当前对象、附件和发送动作位于输入区底部。
- 任务运行时发送动作切换为单一取消入口；不能同时提交第二个任务。

## 12. 漫画与图片视觉

### Comic Paper

- 白色纸张、轻边框和克制阴影。
- 当前页面使用小型页面标签，不增加大标题条。
- 画格边框、遮罩、阅读顺序和纸面辅助线只服务漫画编辑语义。
- 单页与双页查看保持同一种纸张语言；真正双页显示装订关系。

### Selection Focus

- 画格、格内图片、气泡和画布图片使用各自合适的选中轮廓。
- 选中框不进入预览和导出。
- 裁切态明确区分“移动图片取景”“缩放图片取景”和“沿单轴调整画格角点”。
- 多选同时表达漫画对象组和画布图片对象组，避免跨层误操作。

### Reference Image

- 图片主体优先，名称和操作只在 hover、focus、选中或菜单中出现。
- 图片可以自由缩放，但菜单、标签和操作按钮保持固定屏幕尺寸。
- 画布图片与漫画纸张保持清楚层级，不能看起来像已经进入成稿。

## 13. 状态、图标与 QA

| 状态 | 视觉要求 |
|---|---|
| Default | 低强调，内容优先。 |
| Hover | 轻背景或边界变化，不产生位移。 |
| Focus / Selected | 青色结构提示与清楚轮廓。 |
| Referenced | 显示引用标识和可移除关系。 |
| Candidate | 琥珀或中性候选标签，保留范围说明。 |
| Running | 轻量进度和停止入口，旧内容保持可见。 |
| Applied / Saved | 明确文字状态，不持续高亮。 |
| Failed | 错误提示、原因和重试入口。 |
| Stale | 降低强调，说明基于旧工作稿且不可直接应用。 |
| Disabled | 降低对比，同时保留可辨标签或原因。 |

图标使用统一线性语言、圆角端点和接近的 stroke weight。常用概念保持稳定：选择、平移、页面、资产、编排、文字、AI、预览、撤销、重做、保存和删除。陌生动作在菜单中使用图标加文字。

视觉与交互 QA 至少检查：

- 漫画纸张是否仍是第一视觉主体。
- 左右抽屉收起后是否保留恢复入口。
- 浮层是否避开当前选择且不超出安全视区。
- 直接编辑、候选预览和已应用状态是否容易区分。
- 菜单、选择器和对话是否可以键盘操作并正确关闭。
- 预览与导出是否隐藏全部编辑辅助层。
- 画布缩放后，UI 菜单和标签是否仍保持固定可读尺寸。
