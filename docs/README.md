# 文档

## 阅读顺序

1. [产品概要](./product.md)：产品为什么存在、服务谁、坚持什么。
2. [产品需求](./prd.md)：用户能力、对象生命周期、产品范围与验收。
3. [漫画能力矩阵](./capabilities.md)：漫画能力的独立分解、工作台与 MCP 的当前接入状态，以及内置 Agent 保留原型的既有覆盖。
4. [编辑器体验](./editor.md)：工作台交互、视觉系统、状态、动效和可访问性。
5. [LCD](./lcd.md)：作品结构、坐标、分层、资源引用和写入不变量。
6. [Agent](./agent.md)：整体架构、能力边界、上下文、消息、任务、候选、MCP、Skill 和扩展方向。

运行中的工作台是交互与视觉实现基线。

领域参考：[漫画页面效果与编排](./composition.md)梳理常见漫画视觉效果和编排方式，不承担产品范围、协议或实现状态。

使用指南：[外部 Agent 创作快速上手](./agent-quickstart.md)通过可直接使用的 Prompt 演示 MCP + Skill 的基础创作方式。

动态资料：[产品计划](./plan.md)维护可新增、删除和调整优先级的后续产品方向，不定义当前能力、版本范围或 MVP 验收。

## 生命周期基线

| 内容 | 含义 | 写入方式 |
|---|---|---|
| 工作稿 | 用户正在编辑的一话 | 确定性编辑或候选应用通过 ChangeSet 创建新 revision |
| 候选 | 尚未采用的生成、结构或高风险结果 | 预览后显式应用，不能静默覆盖工作稿 |
| Agent 草稿 | 外部 Agent 一次任务的隔离编辑状态 | 基于正式工作稿连续形成草稿 revision，不改变正式作品 |
| Agent 方案 | Agent 草稿冻结后的整体审查结果 | 用户应用并保存、保留或丢弃；过期方案需确认覆盖风险 |
| 保存快照 | 阅读和导出的不可变基线 | 用户显式保存，后续编辑不能原地改写 |

会话、消息、任务、画布图片卡、未应用候选、Agent 草稿和方案都不是正式作品版本。预览与导出只读取 SavedSnapshot 中的 LCD 和固定资源版本。

## 维护规则

- 一个概念只在一份正式文档中完整解释，其他文档使用短引用。
- 正式文档直接描述规则与验收，不记录旧方案、阶段过程或完成日志。
- 新增、删除或调整漫画能力，或改变 UI 编辑器、MCP 的开放范围时，先更新漫画能力矩阵，再同步 README 核心能力表中对应的压缩能力域和接入状态；内置 Agent 保留原型发生明确范围变化时只更新其既有覆盖，不将其表述为当前产品入口。
- 调整 MCP 工具投影、外部结果接入、Skill 通用规则、Capability 同步发布方式或 Agent 能力范围时，同步更新 Agent 文档。
- 产品计划可以独立新增、删除、拆分、合并和调整优先级；计划进入实现并改变当前能力时，再同步更新对应正式事实源和能力矩阵。
- 除 Agent 文档外，`docs/` 不引用源码路径和内部实现符号，也不承担代码导航；LCD 中的稳定对象名与字段名属于作品协议词汇。仓库导航由根目录文档维护。
