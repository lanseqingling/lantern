# 产品需求

## 1. 文档定位

本文定义 Lantern AI 面向个人漫画创作者的核心用户能力、产品范围和验收标准。产品身份与原则见[产品概要](./product.md)，工作台细节见[编辑器体验](./editor.md)，作品结构见[LCD](./lcd.md)。

本文只维护用户能力、产品范围和验收，不承担技术实现说明。

## 2. 产品目标

Lantern AI 帮助个人创作者把故事推进成一话可阅读漫画。核心链路是：

```text
故事目标与参考
  → 轻量故事来源
  → 结构化分镜
  → 页面与阅读节奏
  → 单格生成和局部修改
  → 对白与气泡
  → 阅读检查、保存和导出
```

用户在任何时候都应知道：

- 正在处理哪部漫画、哪一话、哪一页或哪一格。
- 哪些内容是参考、工作稿、候选、页面方案或保存快照。
- 一次操作会影响哪些对象，能否撤销或丢弃。
- AI 准备行动时使用了哪些关键参考，结果如何进入作品。

## 3. 目标用户与核心场景

Lantern 面向有漫画表达欲、但未必掌握完整专业制作流程的个人创作者。他们可能擅长故事、草稿或审美判断，也可能主要依赖文字、参考图和 AI。

核心场景：

1. 从一个故事想法和少量参考开始，不被设定表或资产表单阻塞。
2. 上传角色、场景、构图或单格草稿，作为后续创作参考。
3. 把故事拆成结构化分镜，比较节奏并继续编辑。
4. 将分镜编排为可阅读的页漫，并直接调整画格、取景、对白和阅读顺序。
5. 只生成或修改当前格，不默认影响其他画格或前文。
6. 从当前锚点继续创作，保留已经确认的内容。
7. 保存稳定的一话快照，预览并导出分页图片或结构化数据。
8. 重新进入工作台后恢复工作稿、会话、候选、页面方案和参考摆放。

不优先服务只想一键生成完整漫画的人，也不试图替代职业漫画家的完整绘图软件。

## 4. 产品对象与生命周期

### 4.1 用户可理解的对象

| 对象 | 用户含义 |
|---|---|
| Comic | 一部持续创作的漫画，承载跨话共享事实。 |
| Chapter | 漫画中的一话。 |
| Project | 当前一话背后的创作空间和工作稿。 |
| Story Source | 一话的轻量故事来源，由可版本化段落组成。 |
| StoryboardBeat | 一格要表达的叙事内容，不等于图片或画格。 |
| Presentation Unit | 一次共同阅读和编排的页面、双页或条漫段。 |
| Asset | 角色、场景、风格、道具、参考图、草稿和生成图。 |
| Candidate | 尚未应用到工作稿的生成、结构或高风险结果。 |
| Page Variant | 可以保留并反复预览的页面方案。 |
| Saved Snapshot | 用于稳定阅读和导出的一话快照。 |

LCD 中的 Frame、Layer 和 Element 是作品协议对象，不要求普通用户理解。

### 4.2 工作稿、候选与快照

- 移动画格、调整裁切、改文字等确定性手动操作直接写入可撤销工作稿。
- AI 生成、结构调整、多对象操作、格式切换和其他高风险结果先产生候选。
- 候选应用前不属于作品；应用时校验基准 revision，并作为一次原子变更进入工作稿。
- 一次直接编辑或候选应用全部成功后才生成新 revision，任一部分失败都不改变工作稿。
- Undo / Redo 生成新的有效 revision，不删除历史 revision。
- 页面方案可以预览、重新应用和删除；删除方案不删除当前作品。
- 用户保存一话时从工作稿生成新的不可变快照。旧快照不原地覆盖。
- 预览默认读取保存快照；预览未保存工作稿时必须明确标识。

### 4.3 故事、资产与跨话连续性

- 故事来源保持轻量，只由可版本化段落组成，不建设必须维护的重型剧情树。
- StoryboardBeat 可以固定引用来源段落版本。更新来源不会静默改写已确认分镜或快照。
- 世界观、角色、场景和风格等共享事实属于 Comic；具体章节固定引用本话需要的版本。
- 画布临时图片只属于当前创作空间；用户保存为漫画资产后才进入跨话共享空间。
- LCD、分镜、消息和候选固定引用具体 AssetVersion。解除画布关联不会删除来源资产或破坏历史引用。
- 同一 Project 的不同会话隔离消息与未应用候选，共享已经应用的工作稿和本话可用资产。
- 被工作稿、快照、消息、候选或版本引用的对象不能立即硬删除。

## 5. 漫画格式

- 页漫是完整创作、编辑、阅读与导出闭环的主格式。
- 单页和真正双页共享页面能力；普通双页查看不改变作品结构。
- 条漫复用相同作品对象与编辑能力，在页漫基础稳定后逐步加入纵向节奏、手机视区和切片导出。
- 固定四格不属于推进和验收范围，优先级低于页漫与条漫。
- 同一话只有一个主格式；格式切换产生新编排候选，不破坏原布局。
- mixed 混合格式不进入产品范围。

## 6. 核心工作流

### 6.1 从故事到一话

```text
用故事目标、漫画格式和关键参考形成轻量创作简述
  → 创建漫画与一话
  → 输入或整理故事段落
  → 形成并编辑 StoryboardBeat
  → 生成或直接调整页面编排
  → 逐格生成、精修和调整对白
  → 检查阅读体验
  → 保存快照
  → 阅读预览与导出
```

创作简述组合漫画简介、章节目标、格式和显式参考，不是新的重型对象或多步向导。资产不完整不能阻止用户进入工作区。

### 6.2 直接编辑与 AI 协作

确定性编辑由画布、对象工具条或表单直接完成。需要生成、自然语言理解、结构调整或多对象处理时：

```text
选择对象与引用
  → 说明意图
  → 确认默认作用范围
  → 查看候选或页面方案
  → 应用、继续修改或丢弃
```

普通局部操作默认只影响当前元素或当前 StoryboardBeat。跨格、整页、整话、格式切换和覆盖已确认内容的动作必须显示影响范围并确认。

### 6.3 续写

“继续往下画”默认从当前锚点之后追加 StoryboardBeat 和展示单元。它可以读取前文作为上下文，但不能自动重写前文。

## 7. 功能要求

### 7.1 创作工作台

- 使用全屏创作空间组织左侧资产/分镜/页面、中央漫画舞台、右侧对话和底部创作工具。
- 漫画始终是视觉主体；任务状态只进入对话，不成为画布作品对象。
- 当前选择、直接编辑状态、候选预览和保存状态清楚可辨。
- AI 准备行动或产出候选时，用户能理解焦点、意图、关键参考和影响范围。
- 工作台不提供自由绘制、专业笔刷或复杂参数面板。

### 7.2 资产与参考

- 用户可以上传图片，创建或维护角色、场景、风格和道具资产。
- 画布参考图可摆放、缩放、排序、引用、改名、保存为资产或移除。
- 参考层不进入 LCD、阅读预览或导出。
- 对话附件只服务本轮消息，不自动进入画布或资产库。
- 自动选择参考时，用户可以查看关键参考及使用原因；用户显式引用具有更高优先级。
- 修改图片内容创建新的 AssetVersion，不静默替换其他使用位置。

### 7.3 分镜与编排

- StoryboardBeat 使用简短标题和自然语言描述表达场景、人物、动作、情绪、镜头和叙事目的。
- 用户可以创建、编辑、插入、删除、拆分、合并和重排分镜；未受影响内容保持不变。
- 页面编排与分镜叙事分离，重排页面不能丢失格内成稿、对白或未编排分镜。
- 页漫支持页面、单/双页查看、画格大小、阅读顺序、重点格和翻页节奏。
- 用户可以直接移动和缩放画格、调整格内取景、编辑单格描述和对白。
- 结构性重编排先成为候选或页面方案。

### 7.4 单格生成与修改

- 支持为当前格生成图片，并使用角色、场景、风格、草稿和前后格作为参考。
- 支持只修改当前格的表情、动作、背景、构图或指定画面要求。
- 生成结果固定保存为新的资源版本并先成为候选，不覆盖当前版本。
- 用户可以预览、应用、继续修改、丢弃和撤回应用。
- 模型无法可靠保证的约束必须表达为风险或约束强度，不能伪装成绝对锁定。

### 7.5 对白与气泡

- 对白内容与气泡视觉实例分离。
- 用户可以修改文字、气泡形状、位置、尺寸和尾巴目标，不重新生成画面。
- 气泡与画格使用显式阅读顺序。
- 跨格气泡、复杂自动避让和拟声字高级排版不作为核心闭环前置条件。

### 7.6 预览、保存与导出

- 阅读预览隐藏参考卡、选择框和编辑控件，并可定位回对应页面。
- 保存前提示未编排分镜、未应用候选、缺失图片和阅读顺序异常；只有无法阅读或无法恢复的问题阻塞保存。
- 保存生成不可变快照，不影响继续编辑的工作稿。
- 导出支持分页 PNG 和结构化 LCD JSON；导出失败不影响快照。
- JSON 固定包含作品结构、分镜版本摘要和资源版本清单，不承诺完整工程备份或图片二进制打包。

## 8. 状态与失败保护

| 状态 | 用户理解 |
|---|---|
| 已选择 | 当前操作对象。 |
| 参考中 | 本次会读取，但不会进入成稿。 |
| 候选 | 可以预览、应用、继续修改或丢弃。 |
| 生成中 | 旧内容保持可见，任务在后台推进。 |
| 已应用 | 已进入工作稿，尚未必保存。 |
| 已保存 | 已进入稳定快照。 |
| 已失败 | 旧内容不变，可以重试。 |
| 已过期 | 基于旧工作稿，不能直接覆盖当前内容。 |

必须保护用户内容的情况：

- 上传失败不创建半完成资产。
- 模型或导出失败不修改工作稿或快照。
- 任务完成时 revision 已变化，候选标记为过期。
- 图片暂时不可读时保留结构与稳定引用。
- 删除画格时可以保留 StoryboardBeat 为未编排内容。
- 删除参考卡只移除摆放关系，不删除来源资产。
- 格式切换、整页重排和整话操作必须先产生候选。

## 9. 权限、安全与内容边界

- 漫画、对话、输入、上传文件和生成结果默认私有。
- 所有对象查询校验 owner，不通过资源是否存在泄漏他人信息。
- 上传校验文件大小、声明类型和实际内容。
- 只向模型供应商发送当前任务需要的上下文和资源。
- 日志不记录密钥、完整私有输入或长期可访问 URL。
- 用户可以导出自己的作品；对外发布前需要明确素材授权、生成内容使用和侵权处理规则。
- 模型服务的内容安全拒绝转成可理解错误，不产生空白候选或覆盖旧内容。

## 10. MVP 验收

- 用户可以创建并恢复漫画、一话、工作稿和会话。
- 页漫可以从 StoryboardBeat 形成可编辑页面，完成直接编辑、候选预览、保存和导出。
- 上传参考图和草稿可以进入当前格生成上下文。
- 至少一种真实文字模型和图片模型可通过统一模型接入层工作。
- 单格生成和修改只影响明确目标，结果作为候选保存并校验 revision。
- 手动编辑与候选应用通过原子 ChangeSet 写入，并可 Undo / Redo。
- 工作稿、候选、页面方案和保存快照相互独立、可追踪。
- 失败、取消、重试和重新进入页面不破坏已确认内容。
- 一话可以阅读、保存，并导出分页 PNG 和结构化 JSON。

## 11. 非目标

- 完整笔刷、上色、网点、复杂图层和专业印前工作流。
- 一键生成后直接发布整篇漫画的黑盒流程。
- 固定四格、mixed 混合格式和完整条漫专项闭环。
- 多人实时协作、公开社区、付费和商业版权流程。
- 把复杂 Agent 状态、Prompt 工程或连续性数据变成用户必须维护的表单。
